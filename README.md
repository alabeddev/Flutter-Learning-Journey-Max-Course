# رحلة تعلم Flutter 🚀

مرحباً بك! هذا المستودع هو أرشيف لرحلتي في تعلم تطوير تطبيقات الموبايل باستخدام Flutter.
يحتوي هذا المكان على التطبيقات والمشاريع الصغيرة التي قمت ببنائها أثناء دراستي لكورس "Flutter & Dart - The Complete Guide".

## 📂 محتويات المستودع:
* **first_app**: التطبيق الأول (Roll Dice)، وهو تطبيق بسيط لرمي النرد تعلمت فيه أساسيات الـ Widgets والـ State.
* **h_w1**: التطبيق الثاني (Quiz App)، تعلمت فيه كيفية التعامل مع القوائم (Lists) والبيانات والشروط.

## 🎯 الهدف:
توثيق التطور في كتابة الكود وفهم أساسيات إطار عمل Flutter.
